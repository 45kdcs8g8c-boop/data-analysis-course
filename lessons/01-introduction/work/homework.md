## H3. Инструменты

**Series и DataFrame.**

`Series` — одномерная структура данных pandas, представляющая собой последовательность значений с индексами. Например, `home_outcomes` — Series, содержащая значения столбца `action_taken`.

`DataFrame` — двумерная структура данных, представляющая собой таблицу со строками и столбцами. Например, `home_decisions` — DataFrame, содержащий загруженные данные о кредитных заявках.

**nrows и head.**

Параметр `nrows` функции `read_csv()` позволяет ограничить количество строк, загружаемых из CSV-файла. Метод `head()` показывает первые строки уже загруженной таблицы. Например, `home_decisions.head(5)` выводит первые пять строк DataFrame.

**Метод и атрибут.**

Метод — функция, связанная с объектом. Обычно вызывается со скобками. Например, `home_outcomes.value_counts()` подсчитывает количество повторений каждого значения.

Атрибут — свойство объекта, к которому обращаются без скобок. Например, `home_decisions.shape` возвращает размер таблицы: количество строк и столбцов.

**Документация и уточнения.**

Документация pandas: https://pandas.pydata.org/docs/reference/api/pandas.Series.isin.html

В ходе работы использовался метод `isin()`. Из документации было уточнено, что он принимает набор значений и возвращает логическую Series, показывающую, входит ли каждое значение в указанный набор. В работе метод применялся для определения одобренных заявок с исходами 1 и 2: `home_outcomes.isin([1, 2])`.

## H+2. Типы значений — необязательно

**Выполнялось: да.**

Для проверки влияния типов данных столбец `action_taken` был загружен с типом `string`.

Затем сравнивались два выражения: `text_example["action_taken"].eq(1)` и `text_example["action_taken"].eq("1")`.

При сравнении со значением `1` числового типа результатом стали **[указать результат и количество True]**, поскольку значения столбца представлены строками.

При сравнении со значением `"1"` строкового типа результатом стали **[указать результат и количество True]**.

Таким образом, при сравнении значений важно учитывать тип данных. Число `1` и строка `"1"` являются разными значениями, поэтому для корректного сравнения тип искомого значения должен соответствовать типу данных в столбце.
